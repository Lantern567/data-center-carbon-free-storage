# 方向二：无碳供电与储能研究工作目录

本目录把设备资源需求、IT 功率、散热需求和气候相关配套负荷作为储能与无碳供电研究的输入。方向二独立维护供电合同、电价、储能、CFE 核算和经济性边界；共用负荷输入时保留其版本、服务口径和模型适用范围。

## 已有负荷证据

[20261025-v4 工作包](results/compute-center-data-audit-20261022/coupled-power-weather-20261025-v4/README.md)包含完整报告、实测 CPU/GPU 整机功率点、冷却模型系数、硬件数量、年度与月度汇总，以及现有科学核验记录。完整小时数据位于服务器成果包内。

采用 `facility_mw` 作为设施电力需求时，同时保留 `it_mw`、`cooling_mw`、`other_mw` 和资源需求字段。`heat_demand_mw_th` 表示设备散热需求；电力平衡按设施电功率分项计算。情境规模按参考高负载 IT 功率定义，配电与冷却工程容量需另外核算。

CPU 使用率映射到 SPECpower 整机功率、GPU 申请份额映射到 HGX 整机实测功率，均属于跨数据集代理。ESIF 冷却关系迁移到其他机房时，仍需核对供水温度、热接口和容量。天气与模型校准范围以外的小时在结果中标记。

## 目录

- `analysis/`：本次负荷工作包的生成、绘图、报告和核验脚本，保留计算来源版本。
- `results/`：报告、参数、图件和经核验的汇总。
- `data/metadata/`：数据来源、版本、假设与校验记录。
- `data/raw/`、`data/interim/`、`data/processed/`：按许可存放的本地数据，数据文件默认不提交。

重新生成结果前恢复脚本指向的源文件；已生成的 Parquet/CSV 可独立读取。价格、服务协议和储能参数尚未识别的部分保持待确认，现有负荷计算不提供最优储能容量、成本或收益结论。
